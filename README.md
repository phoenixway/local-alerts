# Тривога • Локально | Android 1.0.0

Нативний Android-застосунок із темним інтерфейсом для **особистого** моніторингу повітряних тривог та сповіщень про початок і відбій.

## Можливості

- **Статус**: червоний / зелений / немає актуальних даних, кнопка ручної перевірки.
- **Події**: останні 40 зафіксованих змін.
- **Settings**: населений пункт, громада, район, область, персональний токен alerts.in.ua, перемикач фонового моніторингу, незалежні перемикачі сповіщень про початок і відбій.
- **За замовчуванням**: Щасливе, Пристолична громада, Бориспільський район, Київська область.
- **Фоновий режим**: видимий Android Foreground Service типу `specialUse`; перевірка приблизно кожні 45 секунд при нормальній роботі; старт після перезавантаження, якщо Android дозволяє.
- **Перше зчитування**: якщо вже є тривога, сповіщення про початок; якщо вже немає, не видається хибний «відбій».
- **Стан API недоступний**: показується **«Статус невідомий»**, не робиться висновок про відбій.

## ВАЖЛИВО: джерело даних і API-токен

Використовується `GET https://api.alerts.in.ua/v1/alerts/active.json` із заголовком `Authorization: Bearer <ваш токен>`. API **вимагає персонального токена**. Отримайте його через https://devs.alerts.in.ua/ і вставте в додатку в Settings, потім увімкніть фоновий моніторинг та збережіть налаштування.

**Токен не вбудований в APK**, у Gradle/вихідні файли або публічні збірки. Він зберігається в приватних налаштуваннях конкретного встановлення; резервне копіювання Android вимкнене. Публікація застосунку з централізованим токеном потребує власного захищеного проксі, згідно з вимогами сервісу.

API docs: https://devs.alerts.in.ua/

Логіка збігу: **обласна** тривога для області; **районна** для району; **громадська** для громади; **міська** для вказаного населеного пункту (якщо повідомляється окремо). Порівнюються назви та область, для міста за наявності також район. Для будь-якої іншої локації користувач сам вводить точні адміністративні назви, як в API. Немає геолокації, GPS дозволи не потрібні.

## Зібрати APK на Fedora / Android Studio

Вимоги: Android SDK Platform 37, JDK 17+ та Gradle 9.3.1 / Android Gradle Plugin 9.1.1 (вказано у конфігурації). Можна імпортувати директорію в Android Studio як Gradle-проєкт. У проєкті тепер є автономний `./gradlew`: він **не залежить від `checkout-guard`**; якщо wrapper JAR відсутній, під час першого запуску він завантажить офіційний JAR Gradle 9.3.1 та перевірить SHA-256. Офіційний дистрибутив Gradle також перевіряється за SHA-256. Для першої збірки потрібен інтернет. Ніяких інших Gradle wrapper файлів із сусідніх проєктів копіювати не потрібно.

```bash
unzip TryvohaLocal-source.zip
cd tryvoha-local
./test-matcher.sh
./build-apk.sh
```

Після успішної збірки:

```
~/Downloads/Tryvoha-Local-1.0.0.apk
```

Встановлення з комп'ютера з увімкненим USB debugging:

```bash
adb install -r "$HOME/Downloads/Tryvoha-Local-1.0.0.apk"
```

Або перенесіть APK на Android, відкрийте його через менеджер файлів і підтвердіть встановлення з цього джерела.

> У середовищі, де створено цей архів, Android SDK відсутній, тому **APK тут не збирали і на телефоні не перевіряли**. Були пройдені лише 17 локальних Java-тестів і перевірка синтаксису Java.

## Початкове налаштування

1. У Settings вставити API-токен, перевірити локацію, увімкнути «Фоновий моніторинг».
2. Увімкнути потрібні перемикачі сповіщень і натиснути **«Зберегти налаштування»**.
3. Надати Android дозвіл на сповіщення. У Settings є посилання на системні дозволи й кнопка тестового сповіщення.
4. У системних налаштуваннях батареї дозволити застосунку роботу без обмежень, де це можливо.
5. Перевірити вкладку **Статус**, зокрема час останньої успішної перевірки, та переконатися, що видимий постійний індикатор фонового моніторингу.

## Обмеження / безпека

- **Не є офіційною системою оповіщення і не замінює сирени, офіційні канали, укриття.**
- Інформація може затримуватися на боці сервісу. Android може відкладати мережеві запити в Doze, вимикати фонові служби, а також блокувати сповіщення, якщо дозвіл відхилено, пристрій вимкнено чи застосунок примусово зупинено.
- Інтервал перевірки **45 секунд, не миттєвий push**. Після HTTP 401 і 429 застосунок робить паузу 3 хвилини, не створюючи хибний відбій. API ліміти: https://devs.alerts.in.ua/
- Якщо дані не оновлювалися понад 4 хвилини або виникла помилка мережі, статус **невідомий**, навіть якщо попередній стан був зеленим.
- Android-системні канали сповіщень можна окремо вимикати в системних налаштуваннях незалежно від перемикачів додатка.
- На деяких телефонах перезапуск після завантаження ОС може бути заблокований виробником. Після примусової зупинки Android може не доставляти `BOOT_COMPLETED`, поки застосунок не відкриють вручну.

## Технічні деталі

- Java 17, Android Framework API, жодних сторонніх Android-бібліотек, мін. Android 8 (API 26).
- Package: `ua.schaslyve.tryvoha`.
- `AlertMatcher` і `TransitionPolicy` не мають Android-залежностей; тести запускаються звичайним `javac`.
- Відповідь API парситься лише за HTTP 200 з коректним `alerts` JSON; 401/429, некоректний JSON, відсутність мережі не є доказом відбою.
- Foreground Service типу `specialUse` призначений для персонального sideload. Для публікації у Google Play цей тип потребує перевірки обґрунтування.

## Що перевірити на реальному телефоні

- Тестове сповіщення зі звуком, підтвердження permission.
- Початок/відбій для тестового сценарію на контрольованому тестовому API або реальних подіях без ризикового очікування.
- Не надсилати кілька однакових сповіщень поспіль.
- При відключенні інтернету не показувати зелене «Тривоги немає».
- Після зміни локації скидається попередній статус.
- Збереження вимкнених каналів сповіщень та поведінка після перезавантаження.
